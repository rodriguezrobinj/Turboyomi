# Seguridad

Si encuentras una vulnerabilidad en Turboyomi, no abras un issue público: repórtala en privado desde
[Security → Report a vulnerability](https://github.com/rodriguezrobinj/turboyomi/security/advisories/new).

Solo se mantiene la última versión publicada.

Las extensiones son de terceros: un fallo dentro de una extensión se reporta a su repositorio. Sí es de
Turboyomi cualquier forma en que una extensión salga de lo que el cargador (`extension-loader`,
`android-compat`, `compat-shims`) o el navegador embebido le permiten.
